Practice Questions

Q1. Which cloud service model provides developers with a platform to build, test, and deploy applications without managing the underlying infrastructure?

  1. Infrastructure as a Service (IaaS)
  2. Platform as a Service (PaaS)
  3. Software as a Service (SaaS)
  4. Function as a Service (FaaS)

Q2. In a symmetric encryption scheme, the same key is used for both encryption and decryption. Which algorithm is an example of symmetric encryption?

  1. RSA
  2. ECC
  3. AES
  4. Diffie‑Hellman

Q3. What is the binary representation of the decimal number 173?

  1. 10101101
  2. 10101011
  3. 11010101
  4. 10110101

Q4. Which protocol operates at the transport layer and provides reliable, connection‑oriented data delivery?

  1. UDP
  2. ICMP
  3. TCP
  4. IP

Q5. A digital signature ensures which two security properties?

  1. Confidentiality and availability
  2. Integrity and non‑repudiation
  3. Authentication and confidentiality
  4. Authorization and integrity

Q6. In the context of operating systems, what does the term “context switch” refer to?

  1. Changing the CPU clock speed
  2. Saving the state of a process and loading another
  3. Swapping memory pages to disk
  4. Updating the file system metadata

Q7. Which data structure uses a Last‑In‑First‑Out (LIFO) principle?

  1. Queue
  2. Linked list
  3. Stack
  4. Tree

Q8. The term “edge computing” primarily aims to:

  1. Centralize all data processing in a single data center
  2. Reduce latency by processing data near the source
  3. Increase bandwidth consumption on the core network
  4. Eliminate the need for cloud services

Q9. Which of the following is a characteristic of a NoSQL database compared to a relational database?

  1. Fixed schema and ACID transactions
  2. Schema‑less design and horizontal scaling
  3. Complex joins and normalized tables
  4. Strict referential integrity constraints

Q10. In Boolean algebra, the expression (A + B)·(A + C) simplifies to:

  1. A + BC
  2. A·B + A·C
  3. A + B + C
  4. A·(B + C)

Answer Key with Explanations

Q1. Answer: (b) Platform as a Service (PaaS) - PaaS supplies a development platform while the provider manages servers and networking.

Q2. Answer: (c) AES - AES is a widely used symmetric block cipher; RSA, ECC, and Diffie‑Hellman are asymmetric.

Q3. Answer: (a) 10101101 - 173 = 128+32+8+4+1 = 10101101 in binary.

Q4. Answer: (c) TCP - TCP provides reliable, ordered, connection‑oriented delivery; UDP is connectionless.

Q5. Answer: (b) Integrity and non‑repudiation - Digital signatures verify that data has not been altered and bind the signer to the message.

Q6. Answer: (b) Saving the state of a process and loading another - A context switch stores the current process context and restores another's.

Q7. Answer: (c) Stack - Stack follows LIFO; queue follows FIFO.

Q8. Answer: (b) Reduce latency by processing data near the source - Edge computing brings computation closer to data generators.

Q9. Answer: (b) Schema‑less design and horizontal scaling - NoSQL databases favor flexible schemas and scale out across nodes.

Q10. Answer: (a) A + BC - Using distributive law: (A+B)(A+C) = A + BC.

Common Mistakes

  • Confusing PaaS with SaaS and selecting IaaS for platform‑level services.
  • Assuming RSA is symmetric because it uses keys for both encryption and decryption.
  • Misapplying Boolean algebra rules and forgetting the absorption law.

Quick Tips

  • Memorize the OSI layer functions; transport layer = TCP/UDP.
  • Practice binary‑decimal conversions daily for speed.
  • Remember that digital signatures provide integrity and non‑repudiation, not confidentiality.
  • Use the distributive and absorption laws to simplify Boolean expressions quickly.
