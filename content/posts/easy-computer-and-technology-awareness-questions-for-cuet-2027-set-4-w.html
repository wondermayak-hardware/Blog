Q1. Which protocol is used for secure web browsing?

  1. HTTP
  2. FTP

  4. SMTP

  1. Internet of Things
  2. Integration of Technology

  1. SaaS

  1. Arithmetic Logic Unit
  2. Advanced Logic Unit
  3. Application Level Unit
  4. Automated Loading Unit

Q8. Which file format uses lossless compression for images?

  1. JPEG
  2. PNG
  3. GIF
  4. BMP

Q9. What is the purpose of a firewall in network security?

  1. Increase bandwidth
  2. Monitor and control incoming/outgoing traffic based on rules
  3. Store backup data

Q10. Which programming language is primarily used for developing Android apps?

  1. Swift
  2. Kotlin

Answer Key with Explanations

Q1. Answer: (c) HTTPS - HTTPS adds TLS/SSL encryption to HTTP for secure browsing.

Q2. Answer: (a) Internet of Things - IoT refers to interconnected physical devices communicating over the internet.

Q3. Answer: (b) WHERE - WHERE filters rows before any GROUP BY aggregation occurs.

Q4. Answer: (b) AES - AES (Advanced Encryption Standard) is a widely used symmetric cipher.

Q5. Answer: (b) Translate domain names to IP addresses - DNS resolves human‑readable names to numeric addresses.

Q6. Answer: (c) IaaS - Infrastructure as a Service delivers virtual machines, storage, and networks.

Q7. Answer: (a) Arithmetic Logic Unit - The ALU performs arithmetic and logical operations in the CPU.

Q8. Answer: (b) PNG - PNG uses lossless compression, preserving image quality.

Q9. Answer: (b) Monitor and control incoming/outgoing traffic based on rules - Firewalls enforce security policies on network packets.

Q10. Answer: (b) Kotlin - Kotlin is the official language for modern Android development.

Common Mistakes

  • Confusing HTTP with HTTPS and missing the security aspect.
  • Thinking HAVING filters rows before grouping instead of after.
  • Assuming RSA is symmetric because it is widely known.

Quick Tips

  • Memorize the full forms of common acronyms (IoT, DNS, ALU, IaaS).
  • Practice distinguishing symmetric vs. asymmetric algorithms.
  • Use elimination: discard obviously unrelated options first.
  • Review cloud service models (SaaS, PaaS, IaaS, FaaS) with real‑world examples.
